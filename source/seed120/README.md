# 120 配对复验的源码归档

- `phase1/`：四路执行器与未改动的搜索／验算模块。
- `phase2/`：依用户要求增加到八路的追加执行器，保留原 job ID、136 条旧结果和半配对原核心。
- `analysis/`：独立验算、统计报告与图表脚本。

这里保存当时使用的源代码。算法和执行器副本保持原字节，因此保留了原实验环境的目录配置；运行前需改为自己的工作区、LKH 路径和 CPU 配置。原数据、训练权重、LKH 可执行文件、软件与缓存均未附带，不能直接开箱复跑完整实验。

推理代码使用 NumPy，资源管理使用 psutil，画图使用 Matplotlib；计时与进程清理实现依赖 Windows Job。完整实验设置、两阶段变化与统计限制见 [报告](../../reports/seed120_20261028/analysis/中文结果报告.md)。
