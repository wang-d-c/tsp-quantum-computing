# 历史五轮实验源码归档

这里保留五轮历史实验 `source` 目录中的文本源码，按原实验目录分别存放。复制后的源码字节与原文件一致；来源相对路径、文件大小和 SHA256 见 `source_manifest.json`。本目录未包含地图坐标、原始路线、逐运行结果、模型权重、训练轨迹、运行日志、二进制程序、编译器或缓存。

这是历史源码存档，保留了当时的配置与代码常量。部分脚本含原运行机的路径，需要改为使用者自己的路径，并单独准备输入、训练或取得模型、配置所需的 LKH 可执行文件。源码中的路径不表示本仓库包含对应文件。

旧轮次的测试地图、随机种子及 A 基线并不完全相同：早期 A 通常是付费最近邻初解再进入 LKH；深度前处理的 A 是普通 LKH 正常初始化；内部深度实验又采用共同付费最近邻兜底。各轮相对数值应按本轮基线解释，不能跨轮直接排名。

本目录并非包含所有运行依赖的独立发行包。特别是内部 LKH 实验，原 `source` 目录只有 Python 调度、训练和核验脚本，本次未包含原生 C 引擎源码或二进制。运行脚本前应阅读对应研究报告，并自行补齐缺少的依赖；不要把缺失依赖误认成仓库里已经提供的文件。

本次最新 120 配对实验是另一次固定版本的种子复验，其运行器和报告单独存放；这里的历史代码保持原样，没有为了得到不同结果进行修改。
