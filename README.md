# TSP 优化思路、实验报告与复现源码

分层贪心、组内 Or-opt／3-opt、路线池、kNN、强化学习候选选择和量子选择设想的研究记录。更新于 **2026-10-28**。

## 最新结论

最新 12 图 × 10 个新配对种子、240 次运行、每次 30 秒的复验，**尚未证明深度候选 2-opt＋LKH 稳定击败原版 LKH**。

双方均有 LKH 输出的 98 配对，平均短 **0.015599%**，23 胜／48 平／27 负，事后条件统计区间跨零。全部 120 配对的 −18.120579% 主要由未输出时的不同兜底路线造成，不能当作 LKH 精修优势。当前实验没有执行量子计算。

## 包含范围

本仓库发布文档、讨论、汇总报告、图表、独立复核摘要和复现源码。用户提供的四份 Markdown 保留为发布副本，补上了最新实验入口，修正了原本地路径和软件附件说明；本机原文件没有改动。文件清单与 SHA256 根据本次实际内容重新生成，不沿用包含软件／数据的旧清单。

原始测试图、坐标、路线、模型权重、训练轨迹、逐种子 CSV／JSON、运行日志、缓存、LKH 可执行文件及 MarkText 软件包均不上传。文档中的汇总数值属于实验报告。源码包含原环境路径配置，复现需另行准备输入、模型与 LKH，并配置本地路径。

实验开始时使用四路；依用户要求，保留已完成的 136 次结果，将余下 104 次改为八路不同物理核心，配对双方同核心依次运行。报告披露两个执行环境，不能把运行环境差异解释成算法加速。
